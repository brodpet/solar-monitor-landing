Flash Gateway

Install the JK BMS gateway firmware on an ESP32 board straight from your browser — no tools to install.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a desktop computer.
Flashing needs a secure connection. Open this page over https.
Build 2383d4c · ESP32 (esp32dev) · Chrome / Edge desktop

Flash

  1. Plug the ESP32 into this computer with a USB data cable.
  2. Click Install Firmware and pick the board's serial port.
  3. Choose to erase the device, then wait for it to finish.

Then set up

  1. Open the Solar Monitor app on your phone.
  2. Join the Wi-Fi hotspot JK-BMS-Gateway-XXXX — password jkbmsgateway.
  3. Run the setup wizard in the app.

No port showing?

  • Try another cable — many are charge-only.
  • Install the USB driver for your board: CP210x or CH340.
  • If it won't connect, hold the BOOT button while clicking Install.

Erasing wipes any saved Wi-Fi and gateway settings on the board.
